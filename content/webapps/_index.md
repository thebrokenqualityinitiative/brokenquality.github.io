## XmR Chart-It

The XmR Chart-It web app is a free to use XmR chart generating tool. It allows users to generate an XmR chart from a list of existing datasets or upload their own dataset as CSV. For those that are unfamiliar with the XmR chart, the app serves as a practical introduction to understanding variation through the lens of process behavior charts. For those familiar with it, it serves as a free alternative to pay-to-play software. Give it a try and let us know what you think!

## Taguchi Loss Calculator

The Taguchi loss calculator is a web application that allows users to put the otherwise theoretical ideas of the Taguchi loss function to work. By allowing users to calculate the economic loss due to poor quality using a quadratic loss function, the calculator reveals that the moment a process produces parts off-target an economic cost is incurred. This cost increases quadratically until the function reaches the specification limits where parts are either scrapped or reworked.

## Honest Process Capability Analysis 

The Honest Process Capability Analysis web application allows users to calculate the process capability indexes by selecting an existing dataset or uploading one of their own. The app calculates the four standard indexes in common use today, capability ratio (Cp), centered capability ratio (Cpk), performance ratio (Pp), and centered performance ratio (Ppk). The overview tab provides a brief but detailed discussion of each of the four indices and the formulas tab outlines the equations used in the calculation of each index, as well as the terms that compose them. In addition to calculating the indices, the app calculates the fraction noconforming, biased point estimate, and the upper and lower interval estimate for the biased point estimate using the Agresti-Coull Interval Estimate method.
